# Prompt — Direção visual no Figma

Crie uma proposta visual profissional para o site descrito abaixo.

A proposta deve funcionar como direção visual para desenvolvimento, não como produto final.

---

[COLE AQUI O RESUMO DO BRIEFING E DO MVP]

---

## Objetivo

Definir uma linguagem visual suficientemente clara para orientar posteriormente a implementação frontend.

Priorize:

- hierarquia visual;
- composição;
- tipografia;
- cores;
- espaçamentos;
- tratamento de imagens;
- botões;
- ritmo entre seções;
- comportamento responsivo.

## Direção da interface

A interface deve refletir as características e sensações identificadas no briefing.

Não aplique automaticamente tendências como glassmorphism, gradientes, excesso de cards, aparência SaaS, sombras pesadas, estética futurista ou animações decorativas.

Utilize esses recursos somente quando forem coerentes com o projeto.

## Layout

Proponha a composição das principais seções do MVP.

Evite transformar todas as seções no mesmo padrão de texto à esquerda e imagem à direita.

Crie variedade controlada de composição mantendo consistência visual.

Considere:

- áreas de maior impacto;
- áreas mais contidas;
- alternância de fundos quando apropriado;
- diferentes proporções de imagens;
- espaço negativo;
- ritmo vertical.

## Design system

Defina uma direção para:

- paleta;
- tipografia display;
- tipografia de corpo;
- escala tipográfica;
- botões;
- links;
- containers;
- espaçamentos;
- bordas;
- imagens;
- estados de interação.

## Responsividade

Considere desktop e mobile.

Não trate mobile apenas como uma versão empilhada do desktop.

Priorize a jornada e a ação principal do usuário em telas menores.

## Restrições

Não invente:

- informações sobre o cliente;
- serviços;
- preços;
- depoimentos;
- certificações;
- funcionalidades.

Quando algum asset estiver ausente, utilize placeholder claramente identificável.

O resultado deve servir como referência suficientemente clara para implementação posterior em React e CSS.
