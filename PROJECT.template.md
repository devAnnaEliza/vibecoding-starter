- headings corretos;
- alt text;
- foco visível;
- contraste adequado;
- navegação por teclado;

## 19. Performance

Priorizar:

- imagens otimizadas;
- prevenção de layout shift;
- lazy loading quando apropriado;
- mínimo JavaScript necessário;
- poucas dependências;
- carregamento eficiente de fontes.

## 20. SEO

- lang;
- title;
- meta description;
- Open Graph;
- headings;
- conteúdo indexável;
